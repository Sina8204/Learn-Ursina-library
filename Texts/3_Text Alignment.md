**Text Alignment** در Ursina با استفاده از خاصیت **`.origin`** کنترل می‌شود:

## مفهوم Origin (مبدأ)

`.origin` یک جفت مختصات `(x, y)` است که تعیین می‌کند **نقطه مرجع** متن کجا قرار بگیرد. محدوده این مختصات معمولاً از `-0.5` تا `0.5` است.

## مثال‌های عملی

### ۱. حالت پیش‌فرض (بالا-چپ):
```python
Text('Hello\nWorld!', origin=(-0.5, 0.5))
```
- **x = -0.5**: متن از **چپ** شروع می‌شود
- **y = 0.5**: متن در **بالا** قرار می‌گیرد
- این مثل رفتار معمولی یک ویرایشگر متن است

### ۲. حالت وسط‌چین (کاملاً وسط):
```python
Text('Hello\nWorld!', origin=(0, 0))
```
- **x = 0**: متن در **وسط افقی** قرار می‌گیرد
- **y = 0**: متن در **وسط عمودی** قرار می‌گیرد
- هم از نظر افقی و هم از نظر عمودی در مرکز است

## مقادیر ممکن برای Origin

| مختصات | معنی |
|---------|------|
| `(-0.5, 0.5)` | بالا-چپ (پیش‌فرض) |
| `(0, 0.5)` | بالای-وسط |
| `(0.5, 0.5)` | بالا-راست |
| `(-0.5, 0)` | وسط-چپ |
| `(0, 0)` | وسط-وسط |
| `(0.5, 0)` | وسط-راست |
| `(-0.5, -0.5)` | پایین-چپ |
| `(0, -0.5)` | پایین-وسط |
| `(0.5, -0.5)` | پایین-راست |

## مثال کامل:
```python
# متن در گوشه بالا-چپ (پیش‌فرض)
Text('Start Game', origin=(-0.5, 0.5))

# متن وسط صفحه
title = Text('Game Title', origin=(0, 0), scale=2)

# متن در گوشه پایین-راست
Text('Version 1.0', origin=(0.5, -0.5))
```

## نکته مهم:
- مقادیر منفی `-` یعنی **چپ** یا **پایین**
- مقادیر مثبت `+` یعنی **راست** یا **بالا**
- عدد `0` یعنی **دقیقاً وسط**

با تغییر `.origin` می‌توانید متن را هر جایی که نیاز دارید، دقیقاً تراز کنید! 🎯
