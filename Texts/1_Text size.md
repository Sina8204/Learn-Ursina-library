
## 1. تنظیم هنگام ساخت Text Entity
با استفاده از پارامتر `world_scale` می‌توانید سایز متن را مستقیماً هنگام ایجاد مشخص کنید:

```python
text_entity = Text('hello', world_scale=2)  # متن دو برابر بزرگتر از پیش‌فرض
```

## 2. تغییر سراسری (Global) سایز تمام متون
با تغییر `Text.size` می‌توانید سایز پیش‌فرض همه متون را تغییر دهید:

```python
Text.size = .05  # مقدار پیش‌فرض .025 است، پس این کار متن‌ها را دو برابر بزرگتر می‌کند
```

## 3. تغییر سایز متن در دکمه‌ها (Button)
دکمه‌ها ممکن است مقیاس غیریکنواخت داشته باشند. برای تنظیم سایز متن داخل دکمه:

```python
button = Button(scale=(.2, .1), text='Start')
button.text_entity.world_scale = 2  # متن دکمه را دو برابر بزرگتر می‌کند
```

## نکات مهم:
- **`.scale`** و **`.world_scale`** هر دو برای تنظیم سایز متن استفاده می‌شوند
- مقدار پیش‌فرض `Text.size` برابر **.025** است
- سایز بزرگتر = عدد بزرگتر
- در Buttonها باید از `text_entity.world_scale` استفاده کنید چون دکمه ممکن است مقیاس غیریکنواخت داشته باشد
