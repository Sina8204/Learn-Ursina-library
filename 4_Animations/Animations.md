#Animations

### 1. روش اول: انیمیشن دو بعدی (تک فایل)
این ساده‌ترین حالت است. اگر فایل انیمیشن خود را به صورت یک گیف (GIF) دارید، می‌توانید مستقیماً از کلاس `Animation` استفاده کنید.

**مثال کاربردی** (نمایش یک گیف روی دوربین - مناسب برای منوها یا افکت‌های ویژه):
```python
from ursina import *

app = Ursina()

# اگر اسم فایل شما 'explosion.gif' است
# با استفاده از parent=camera.ui، انیمیشن را روی صفحه (نه در صحنه سه بعدی) نشان می‌دهیم.
gif_animation = Animation('explosion.gif', parent=camera.ui, scale=0.5)

app.run()
```
> **نکته فنی:** برای کار با گیف‌ها، حتما باید کتابخانه `imageio` را نصب داشته باشید (`pip install imageio`).

### 2. روش دوم: انیمیشن دو بعدی با دنباله تصاویر (Sprite Sheet)
این روش برای زمانی است که یک کاراکتر دو بعدی دارید که حالت‌های مختلف (مثلاً ایستادن، راه رفتن) را دارد و شما یک فایل واحد شامل تمام فریم‌ها دارید (Sprite Sheet). در اینجا از `SpriteSheetAnimation` استفاده می‌کنیم.

**مراحل انجام کار:**
1.  **تعیین تعداد فریم‌ها:** ببینید در هر سطر و ستون، چند فریم وجود دارد.
2.  **نقشه برداری (Mapping):** مشخص کنید کدام سطر و ستون متعلق به کدام انیمیشن است.

**مثال کاربردی** (یک کاراکتر با دو حالت "idle" و "run"):
```python
from ursina import *
from ursina.prefabs.sprite_sheet_animation import SpriteSheetAnimation

app = Ursina()

# فرض کنید یک فایل sprite_sheet.png دارید که 2 سطر و 4 ستون دارد (مجموعا 8 فریم)
# سطر اول: حالت Idle (4 فریم)
# سطر دوم: حالت Run (4 فریم)

player = SpriteSheetAnimation('sprite_sheet.png',      # مسیر فایل
                              'idle',                   # حالت پیش‌فرض
                              animations={
                                'idle': (0, 4),         # سطر 0 (اول)، از فریم 0 تا 4
                                'run': (1, 4)           # سطر 1 (دوم)، از فریم 0 تا 4
                              },
                              fps=12,                   # فریم بر ثانیه
                              loop=True,
                              scale=2)

player.x = -2

app.run()
```
در این کد، با فشردن کلیدهای 1 و 2 می‌توانستید حالت را تغییر دهید، ولی برای سادگی، کد فقط حالت `idle` را اجرا می‌کند.

### 3. روش سوم: انیمیشن سه بعدی حرفه ای با Actor
اگر با نرم‌افزارهایی مثل بندر (Blender) یا مایا (Maya) کار کرده باشید، می‌دانید که مدل‌های سه بعدی معمولا دارای استخوان‌بندی (Rigging) هستند و انیمیشن آن‌ها در فایل‌های جداگانه (مثل فرمت `egg` یا `gltf`) ذخیره می‌شود.

در Ursina، قوی‌ترین روش برای این کار استفاده از کلاس `Actor` است (که در پس‌زمینه از موتور پاندا (Panda3D) استفاده می‌کند).

**مثال کاربردی** (بارگذاری یک شخصیت سه بعدی و اجرای انیمیشن راه رفتن):
```python
from ursina import *

app = Ursina()

# مدل و انیمیشن خود را بارگذاری کنید
# فرض کنید فایل model.egg مدل شما و walk.egg انیمیشن راه رفتن آن است
et = Actor('model.egg',          # مسیر فایل مدل سه بعدی
           anim='walk.egg',       # مسیر فایل انیمیشن
           scale=0.5,
           position=(0,0,0))

# اجرای انیمیشن با حلقه بی‌نهایت
et.play('walk')

# دوربین ادیتور برای مشاهده بهتر
EditorCamera()

app.run()
```

### 4. روش چهارم: کنترل وضعیت‌ها با Animator
گاهی نیاز دارید که بین چندین انیمیشن مختلف بر اساس وضعیت کاراکتر جابجا شوید (مثلاً از Idle به Walk یا از Walk به Attack). اینجا جایی است که `Animator` به کار می‌آید.

**مثال کاربردی** (ساخت یک کاراکتر با انیمیشن‌های جداگانه):
فرض کنید سه انیمیشن دو بعدی جداگانه به نام‌های `"idle"`، `"walk"` و `"jump"` دارید.

```python
from ursina import *

app = Ursina()

# --- مرحله 1: ساخت انیمیشن‌های جداگانه ---
# هرکدام را به عنوان یک موجودیت (Entity) مجزا می‌سازیم.
# آنها را خاموش (autoplay=False) می‌کنیم تا بعدا دستی کنترل کنیم.
idle_anim = Animation('idle', parent=camera.ui, autoplay=False, loop=True)
walk_anim = Animation('walk', parent=camera.ui, autoplay=False, loop=True)
jump_anim = Animation('jump', parent=camera.ui, autoplay=False, loop=False)

# --- مرحله 2: تعریف Animator ---
# این شیء وظیفه دارد که مشخص کند کدام انیمیشن در هر لحظه فعال باشد.
animator = Animator({
    'idle': idle_anim,
    'walk': walk_anim,
    'jump': jump_anim,
}, default='idle')  # حالت اولیه را idle قرار می‌دهیم

# --- مرحله 3: تابع ورودی برای تغییر وضعیت ---
def input(key):
    if key == '1':
        animator.state = 'idle'
    elif key == '2':
        animator.state = 'walk'
    elif key == 'space':
        # انیمیشن پرش را اجرا کن و بعد از تمام شدن، به حالت قبلی برگرد
        animator.state = 'jump'
        # بعد از 0.5 ثانیه (زمان تقریبی انیمیشن پرش) دوباره به 'idle' برگرد
        invoke(animator.set_state, 'idle', delay=0.5)

app.run()
```
با فشردن کلیدهای **1**، **2** و **اسپیس** می‌توانید بین انیمیشن‌ها جابجا شوید.

### 5. روش پنجم: ساخت دنباله (Sequence) از انیمیشن‌ها
گاهی نیاز دارید یک سناریوی خاص را اجرا کنید: مثلاً کاراکتر "تعظیم کند"، سپس "بپرد" و بعد "بنشیند". برای این کار از کلاس `Sequence` استفاده می‌شود.

**مثال کاربردی:**
```python
from ursina import *

app = Ursina()

# ساخت چند تابع ساده برای تغییر وضعیت
def anim1():
    print("اجرای انیمیشن شماره 1")
    # فرض کنید: animator.state = 'bow'

def anim2():
    print("اجرای انیمیشن شماره 2")
    # فرض کنید: animator.state = 'jump'

# ساخت دنباله: اول تابع اول را صدا بزن، 0.5 ثانیه صبر کن، بعد تابع دوم را صدا بزن
my_sequence = Sequence(Func(anim1), Wait(0.5), Func(anim2))

# اجرای دنباله
my_sequence.start()
app.run()
```

### یک نکته حرفه‌ای: ساخت انیمیشن با چرخاندن اشیاء
اگر یک شیء ساده مثل یک صفحه یا کارت دارید و می‌خواهید آن را بچرخانید تا جلوه سه بعدی داشته باشد، می‌توانید با تغییر خاصیت `rotation` در تابع `update` یا به کمک `animate`، به صورت برنامه‌نویسی این کار را انجام دهید.

**مثال:** چرخاندن یک سکه
```python
# در تابع update هر فریم، rotation_y سکه را تغییر دهید
def update():
    coin.rotation_y += 10  # هر فریم 10 درجه بچرخ
```

### جمع بندی: کدام روش را انتخاب کنم؟

| وضعیت | بهترین گزینه | دلیل |
| :--- | :--- | :--- |
| **بازی دو بعدی با گیف** | `Animation` | سریع و ساده  |
| **بازی دو بعدی با یک برگه اسپرایت (Sprite Sheet)** | `SpriteSheetAnimation` | بهینه و قابل کنترل  |
| **بازی سه بعدی (مدل‌های پیچیده)** | `Actor` | حرفه‌ای و پشتیبانی از استخوان‌بندی  |
| **مدیریت چندین حالت (Idle, Run, Attack)** | `Animator` | تمیز و بدون خطا  |
| **اجرای پشت سر هم انیمیشن‌ها** | `Sequence` | کنترل زمان‌بندی آسان  |
