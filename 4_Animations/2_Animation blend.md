
**در خود Ursina، به صورت مستقیم و ساده، قابلیتی به نام "Animation Blending" وجود ندارد.** یعنی نمی‌توانید به راحتی بگویید "۶۰٪ انیمیشن راه رفتن و ۴۰٪ انیمیشن دویدن را با هم ترکیب کن".

اما دو راهکار عملی وجود دارد که این قابلیت را به شما می‌دهد:

## راهکار اول: استفاده از Actor پاندا (Panda3D) - مخصوص مدل‌های استخوان‌بندی شده

این **حرفه‌ای‌ترین و توصیه شده‌ترین روش** برای انیمیشن‌های سه‌بعدی با استخوان‌بندی (ریگ) است. Ursina در پس‌زمینه از موتور پاندا استفاده می‌کند، و شما می‌توانید مستقیماً از کلاس `Actor` پاندا بهره ببرید.

**نکته مهم:** مدل شما باید به فرمت‌های `.egg` یا `.bam` تبدیل شود. می‌توانید از ابزار `blend2bam` برای تبدیل فایل‌های بلندر استفاده کنید.

### مثال عملی: ترکیب دو انیمیشن با Actor

```python
from ursina import *
from direct.actor.Actor import Actor

app = Ursina()

# بارگذاری مدل و انیمیشن‌ها با Actor پاندا
# فرض کنید فایل‌های model.egg، idle.egg و walk.egg را دارید
player = Actor("models/model.egg",
               {"idle": "animations/idle.egg",
                "walk": "animations/walk.egg"})

# تنظیم player به عنوان موجودیت (Entity) در Ursina
player_entity = Entity(model=player, scale=0.5, y=1)

# پخش انیمیشن اولیه
player.play("idle")

# تابع ترکیب انیمیشن‌ها (Blending)
def blend_animations():
    # اینجا می‌توانید منطق ترکیب خود را پیاده کنید
    # مثلاً بر اساس سرعت حرکت کاراکتر
    pass

# مثلاً با فشردن کلید shift، انیمیشن walk با idle ترکیب شود
def input(key):
    if key == 'shift':
        # پخش انیمیشن walk با ترکیب 0.5 ثانیه‌ای با انیمیشن فعلی
        player.play("walk", blendTime=0.5)  # blendTime زمان ترکیب را مشخص می‌کند
    elif key == 'shift up':
        player.play("idle", blendTime=0.3)

app.run()
```

**توضیح پارامتر `blendTime`:** این پارامتر مشخص می‌کند که انتقال بین دو انیمیشن در چه مدت زمانی (بر حسب ثانیه) انجام شود. مثلاً `blendTime=0.5` یعنی ۰.۵ ثانیه طول می‌کشد تا انیمیشن قبلی به تدریج به انیمیشن جدید تبدیل شود.

## راهکار دوم: انیمیشن‌های ساده (غیر استخوانی) با FrameAnimation3d

اگر مدل شما استخوان‌بندی (ریگ) ندارد و یک شیء ساده است (مثل یک مکعب در حال تغییر شکل)، می‌توانید از `FrameAnimation3d` استفاده کنید.

**نحوه کار:** شما باید هر فریم انیمیشن را به عنوان یک فایل جداگانه (مثلاً `run_cycle_000.obj`، `run_cycle_001.obj` و ...) داشته باشید.

```python
from ursina import *

app = Ursina()

# فرض کنید فایل‌های obj با نام blob_animation_000.obj، blob_animation_001.obj و ... دارید
# FrameAnimation3d به طور خودکار دنباله فایل‌ها را پیدا می‌کند
animated_blob = FrameAnimation3d('blob_animation_',
                                 fps=24,      # فریم بر ثانیه
                                 loop=True,
                                 scale=1,
                                 position=(0,0,0))

# متاسفانه FrameAnimation3d قابلیت Blending داخلی ندارد
# برای ترکیب باید خودتان منطق جابجایی بین آن‌ها را مدیریت کنید

app.run()
```

> **محدودیت مهم:** این روش **هیچ قابلیت Blending مستقیمی ندارد**. هر بار که بین دو انیمیشن جابجا می‌شوید، یک قطع ناگهانی در حرکت خواهید داشت. به همین دلیل برای پروژه‌های حرفه‌ای، روش اول (Actor) بسیار توصیه می‌شود.

## جمع‌بندی و توصیه نهایی

| ویژگی | Actor (روش اول) | FrameAnimation3d (روش دوم) |
| :--- | :--- | :--- |
| **مناسب برای** | مدل‌های دارای استخوان‌بندی (شخصیت‌ها) | اشیاء ساده بدون استخوان‌بندی |
| **پشتیبانی از Blending** | ✅ دارد (با پارامتر `blendTime`) | ❌ ندارد |
| **فرمت ورودی** | `.egg`, `.bam` (حاصل از `.blend`) | دنباله‌ای از فایل‌های `.obj` |
| **حرفه‌ای بودن** | ⭐⭐⭐⭐⭐ | ⭐⭐ |
| **پیچیدگی** | متوسط | کم |

### مسیر پیشنهادی برای کار با انیمیشن‌های سه‌بعدی:

1. **مدل خود را در بلندر (Blender) مدل و ریگ کنید** (استخوان‌بندی کنید)
2. **انیمیشن‌های مختلف را بسازید** (idle, walk, run, jump, ...)
3. **فایل را با ابزار `blend2bam` به فرمت `.bam` تبدیل کنید**
4. **در Ursina از کلاس `Actor` پاندا استفاده کنید** و با `blendTime` انیمیشن‌ها را ترکیب نمایید
