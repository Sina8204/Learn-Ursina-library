در Ursina، قابلیت سایه‌اندازی به طور کامل برای همه انواع نور پیاده‌سازی نشده است. در حال حاضر، **تنها نور جهت‌دار (`DirectionalLight`) از سایه‌اندازی پشتیبانی می‌کند**. برای استفاده از آن و تنظیمات مربوطه، باید چند مرحله کلیدی را دنبال کنید.

### ☀️ افزودن سایه با نور جهت‌دار

1.  **اعمال شیدر مناسب**: برای اینکه یک آبجکت بتواند سایه دریافت کند، باید از شیدر `lit_with_shadows_shader` استفاده کنید. این کار را می‌توانید برای تک‌تک آبجکت‌ها یا به صورت سراسری انجام دهید.

    ```python
    from ursina import *
    from ursina.shaders import lit_with_shadows_shader

    app = Ursina()

    # روش اول: اعمال به یک آبجکت خاص
    ground = Entity(model='plane', scale=10, shader=lit_with_shadows_shader)

    # روش دوم: اعمال سراسری به همه آبجکت‌های جدید
    Entity.default_shader = lit_with_shadows_shader
    cube = Entity(model='cube', y=1)
    ```

2.  **ایجاد و جهت‌دهی نور**: یک نور جهت‌دار بسازید و پارامتر `shadows=True` را به آن اضافه کنید. با استفاده از متد `look_at()` جهت تابش نور را مشخص کنید.

    ```python
    sun = DirectionalLight(shadows=True)
    sun.look_at(Vec3(1, -1, -1))  # نور از بالا و سمت راست می‌تابد
    ```

### ⚙️ تنظیمات پیشرفته سایه

بعد از فعال‌سازی پایه، می‌توانید کیفیت و ظاهر سایه‌ها را با پارامترهای زیر کنترل کنید.

| ویژگی | توضیح | مقدار پیش‌فرض |
| :--- | :--- | :--- |
| **`shadow_map_resolution`** | وضوح نقشه سایه. عدد کمتر = کیفیت پایین‌تر اما عملکرد بهتر. | `(1024, 1024)` |
| **`shadow_bias`** | برای جلوگیری از "نویز سایه" (shadow acne) که به صورت خطوط مویر روی سطح دیده می‌شود. | `0.001` |
| **`shadow_blur`** | میزان نرمی یا محوی لبه‌های سایه. عدد بیشتر = سایه نرم‌تر. | `0.005` |
| **`shadow_samples`** | تعداد نمونه‌ها برای نرم‌سازی سایه. عدد بیشتر = کیفیت بالاتر و سنگین‌تر. | `4` |

**مثال از تنظیمات:**

```python
sun = DirectionalLight(
    shadows=True,
    shadow_map_resolution=(512, 512),  # کاهش کیفیت برای بهبود عملکرد
)
```

### 🎨 تنظیم رنگ و شدت سایه

رنگ و تیرگی سایه‌ها از طریق شیدر قابل تنظیم است. با تغییر مقدار آلفا (`alpha`) در رنگ `shadow_color`، می‌توانید شدت سایه را کنترل کنید.

```python
from ursina.shaders import lit_with_shadows_shader

# رنگ سایه را به مشکی با شفافیت 50% تنظیم می‌کند (سایه‌ها کمرنگ‌تر می‌شوند)
lit_with_shadows_shader.default_input['shadow_color'] = color.rgba(0, 0, 0, 0.5)
```

### ⚠️ نکات مهم و محدودیت‌ها

*   **سایر نورها**: در نسخه‌های فعلی Ursina، `PointLight` و `SpotLight` علی‌رغم وجود در API، پیاده‌سازی کاملی برای سایه‌اندازی ندارند. نمونه‌هایی از تلاش کاربران برای افزودن `shadows=True` به `PointLight` وجود دارد، اما معمولاً بی‌نتیجه است.
*   **عملکرد**: سایه‌اندازی می‌تواند سنگین باشد. برای بهبود عملکرد، رزولوشن نقشه سایه را کاهش دهید یا از `entity.hide(0b0001)` برای جلوگیری از سایه‌اندازی برخی آبجکت‌ها استفاده کنید. همچنین می‌توانید با `sun.update_bounds(my_scene_parent)` مرز محاسبه سایه را به محدوده صحنه خود محدود کنید.
*   **سازگاری**: شیدر `lit_with_shadows_shader` از نسخه GLSL 150 استفاده می‌کند. اگر با سیستم‌های قدیمی‌تر مشکل دارید، ممکن است نیاز به تغییر در کد منبع Ursina باشد.

به طور خلاصه، برای سایه‌اندازی در Ursina، باید از نور جهت‌دار و شیدر مخصوص استفاده کنید. با تنظیم پارامترهای کیفیت و رنگ سایه، می‌توانید ظاهر آن را تا حد زیادی کنترل کنید.
